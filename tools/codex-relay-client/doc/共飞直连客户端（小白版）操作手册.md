# 共飞直连客户端（小白版）操作手册

> 适用对象：第一次使用共飞直连客户端的普通用户。
>
> 使用目标：完成注册、登录、安装 ChatGPT、切换分组、充值，以及后续在 ChatGPT 里切换模型和推理强度。

## 1. 先看懂这个客户端是做什么的

共飞直连客户端可以理解成一个“帮你把账号、分组、充值、ChatGPT 启动这些事情串起来”的入口。

你平时主要只需要做这几件事：

1. 注册账号；
2. 登录账号；
3. 安装或启动 ChatGPT；
4. 选择分组；
5. 需要时充值；
6. 在 ChatGPT 里切换模型和推理强度。

> 小提醒：平时尽量保持客户端运行，不要直接关闭。  
> 如果你只是最小化窗口，程序通常会留在托盘里继续工作。

## 2. 注册账号

如果你还没有账号，先注册。

操作步骤：

1. 打开客户端，停留在登录页；
2. 点击“还没有账号？注册”；
3. 按页面提示填写邮箱、密码等信息；
4. 如果页面要求验证码，就先完成验证码；
5. 按提示提交注册。

### 如果你看不到注册入口

这通常表示当前服务器没有开放注册，或者管理员关闭了注册功能。  
这种情况下不是你操作错了，而是系统本身暂时不允许注册。

## 3. 登录账号

注册完成后，回到登录页登录。

操作步骤：

1. 输入注册邮箱；
2. 输入密码；
3. 点击“登录”；
4. 如果页面要求你勾选协议，请先勾选再继续；
5. 如果有二次验证，按页面提示完成验证码或验证码输入；
6. 登录成功后，系统会进入主界面。

### 登录后你会看到什么

通常会看到：

- 当前账号信息；
- 当前分组；
- 余额或用量信息；
- “安装 ChatGPT”或“启动 ChatGPT”之类的按钮；
- “去充值”按钮。

## 4. 安装 ChatGPT

如果你的电脑还没有装 ChatGPT，先安装。

操作步骤：

1. 登录成功后，在主界面找到“安装 ChatGPT”；
2. 点击后，客户端会帮你准备安装包或直接拉起安装流程；
3. 按系统安装向导一步一步完成安装；
4. 安装完成后，再回到客户端继续下一步。

### 如果你已经装过 ChatGPT

按钮文案可能不是“安装 ChatGPT”，而是：

- “启动 ChatGPT”
- “重启 ChatGPT 激活账户”

这表示客户端已经检测到本机有 ChatGPT，可以直接启动或重启来接入当前账号。

## 5. 切换分组

分组可以理解为“当前账号正在使用哪一套线路/策略”。

操作步骤：

1. 登录后进入主界面；
2. 找到“当前分组”或“切换分组”区域；
3. 点击分组下拉框；
4. 选择你要用的分组；
5. 选好后等待系统切换完成。

### 切换分组时的几个小提示

- 当前正在使用的分组，一般会有“当前使用中”之类的标识；
- 切换后，余额折算、倍率展示、可用模型可能会跟着变化；
- 如果某个分组不可用，通常会有提示，不用反复乱点。

## 6. 充值

当余额不足时，直接在客户端里充值即可。

操作步骤：

1. 在主界面点击“去充值”；
2. 进入充值页面后，先选择一个充值金额；
3. 如果预设金额不合适，可以手动输入自定义金额；
4. 选择支付方式；
5. 扫码完成支付；
6. 支付成功后，返回主界面或等待余额刷新。

### 充值页面会看到什么

通常会显示：

- 当前余额；
- 充值金额；
- 手续费；
- 实际支付金额；
- 可用支付方式；
- 二维码支付区域。

> 小提醒：充值金额有时会按当前分组倍率折算成额度，这属于正常情况。

## 7. 在 ChatGPT 里切换模型

当 ChatGPT 已经安装并启动后，你可以在 ChatGPT 里切换要使用的模型。

常见操作方式是：

1. 打开 ChatGPT；
2. 在对话窗口上方或模型按钮处找到当前模型；
3. 点击模型名称；
4. 在下拉列表里选择你想要的模型；
5. 选好后继续输入问题即可。

### 使用时的建议

- 如果你要写代码、做长文分析，优先选择更强的模型；
- 如果只是简单问答，可以选更轻量的模型；
- 如果你不确定选哪个，先用默认模型就行。

## 8. 在 ChatGPT 里切换推理强度

有些模型支持设置推理强度，常见叫法可能是：

- 推理强度
- reasoning effort
- 思考强度
- 低 / 中 / 高 / 极高

操作步骤一般是：

1. 打开 ChatGPT；
2. 找到当前模型旁边的设置项；
3. 选择推理强度；
4. 按你的任务需要切换等级；
5. 继续对话。

### 怎么选比较合适

- 低：更快，适合简单问题；
- 中：平衡速度和质量；
- 高：适合更认真地分析问题；
- 极高：适合复杂推理、长链路判断、难题排查。

如果你只是日常使用，可以先从“中”或“高”开始。

## 10. 常见问题

### 10.1 登录后看不到“安装 ChatGPT”

先确认你是不是已经装过 ChatGPT。  
如果已经安装，按钮可能会显示成“启动 ChatGPT”或“重启 ChatGPT 激活账户”。

### 10.2 切换分组后好像没变化

先确认分组是否切换成功，再看当前分组标签有没有更新。  
如果分组本身不可用，界面通常会提示。

### 10.3 充值后余额没马上刷新

可以稍等片刻，或者回到主界面刷新一次。  
如果还是没变，先检查支付是否真的完成。

### 10.4 ChatGPT 里找不到模型或推理强度

不同版本的 ChatGPT 界面位置可能不完全一样。  
你可以优先找：

- 对话顶部的模型按钮；
- 输入框附近的下拉项；
- 设置里的模型相关选项。
