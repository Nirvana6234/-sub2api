# 共飞AI工作台

共飞AI工作台用于管理 Codex、Claude Code、Gemini CLI 的连接来源，并提供项目会话、本地与云端用量统计、中转服务控制等功能。

## 启动

解压完整压缩包后，双击 `共飞AI工作台.exe` 或 `启动共飞AI工作台.cmd`。

请保留目录中的全部文件，不要只复制 EXE。本公开包支持 Windows 10/11 x64，并已包含所需的 .NET 运行环境。

## 基本使用

1. 在“连接中心”添加云端来源，或配置固定的本机中转、局域网中转。
2. 选择各客户端使用的来源后应用分流。
3. 在“项目中心”选择项目，继续已有会话或开始新对话。
4. 在“用量仪表盘”查看本地观测和已登录后台的云端实际用量。
5. 在“中转服务”查看本机或局域网服务状态，并打开对应后台。

未运行本机中转时，可以直接使用云端或局域网中转。登录信息和连接密钥仅保存在当前 Windows 用户的数据目录，不包含在程序发布包中。

## 数据与隐私

程序不会在发布目录保存 API 密钥、登录令牌、提示词或回复正文。本地统计只记录请求数量、Token、成功状态、耗时等用量数据。

卸载程序时删除程序目录即可。如需同时清除本机数据，可在设置页打开数据目录，退出程序后删除该目录。
